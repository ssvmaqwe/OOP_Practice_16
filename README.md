# OOP_Practice_16 — Графічний інтерфейс (текстова гра)

Практичне заняття 16 з дисципліни «Об'єктно-орієнтоване програмування».
Виконала: Фізик Анна, КН-33, 3 курс.

Дизайн-документ: [DESIGN.md](DESIGN.md) (графічний інтерфейс — розділ 11, збереження — розділ 6)

## Запуск

Графічне вікно:

```
pip install -r requirements.txt
python gui.py
```

Консольна версія:

```
python main.py
```

Після перезапуску введіть `continue`, щоб продовжити гру з останнього збереження.
